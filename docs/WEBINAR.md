# Видео-вебинар — решения и план (отложено)

Обсуждено с владелицей 14–15 окт. 2026, **отложено на потом** (решение владелицы 15 окт.).
Когда вернёмся: отдельная сессия и PR; ТЗ ниже можно вставить целиком. Шаги воронки (миграция 014, PR #25) уже есть.

## Решения
- **Хранение — Cloudflare Stream** (рекомендовано и принято без возражений). Цены сверены 14 окт.: $5 за 1000 минут
  хранения в месяц (блоками), $1 за 1000 минут просмотра, загрузка и перекодирование бесплатно. Пример: вебинар 1 час,
  100 зрителей ≈ $5 хранение + ≈ $6 просмотры. Bunny Stream дешевле ($0,01/ГБ хранение, в Азии $0,03/ГБ трафик), но это
  ещё один сервис и счёт. Перед подключением цены сверить снова.
- **Режим просмотра:** по умолчанию — запись, клиент смотрит в любое время. **По желанию эксперт включает «как живой»**
  (решение владелицы: «при желании, чтобы можно было включить»): время начала, без перемотки, опоздавший начинает с
  текущей минуты, напоминание за час.
- **Несколько вебинаров** у одного SI-продавца (рекомендовано, без возражений); каждый можно поставить шагом воронки.

## Что сделать владелице (до сессии)
1. dash.cloudflare.com → аккаунт с `techsmartflow.com` → **Stream** (иногда в разделе «Media») → подключить самый маленький пакет хранения.
2. Скопировать **Account ID** (главная страница аккаунта, справа).
3. Профиль (справа вверху) → **My Profile → API Tokens → Create Token → Create Custom Token**: имя `smartflow-stream`,
   Permissions: **Account → Stream → Edit**, Account Resources: **Include →** свой аккаунт → создать, скопировать ключ (показывается один раз).
4. Railway → сервер → **Variables**: `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_STREAM_TOKEN`. В чат ключи не присылать.

## ТЗ для сессии
1. Офис → SI-продавец → «Вебинары»: несколько вебинаров. Эксперт загружает видео с телефона прямо в Cloudflare
   (одноразовая ссылка на загрузку от сервера; через наш сервер файл не идёт). Название, описание, статус обработки.
   Ключ подписи ссылок сервер создаёт сам через API и хранит в базе.
2. Режим по умолчанию — запись. По желанию — «как живой»: время начала, без перемотки, опоздавший с текущей минуты,
   напоминание за час (Бадди → Telegram, «будильник»).
3. Вебинар — шаг воронки: в шаге можно выбрать вебинар вместо материала-текста; клиент получает в чате кнопку
   «Смотреть вебинар» и смотрит **внутри SmartFlow**.
4. Свой плеер: на iPhone не уходит в системный полноэкранный режим (`playsinline`). Только защищённые ссылки
   (подписанный токен на несколько часов, только для этого клиента). Обещаем «сложно скачать» — запись экрана запретить нельзя.
5. Процент досмотра — по реально просмотренным секундам, перемотка вперёд не считается. События журнала: «начал смотреть»,
   «посмотрел 25/50/75%», «досмотрел». SI знает, сколько клиент посмотрел.
6. Сценарии: «посмотрел меньше N%», «досмотрел», в том числе с «Клиент молчит» (пример: «посмотрел меньше половины и
   молчит 2 часа → SI мягко спрашивает, удобно ли досмотреть»).
7. В «Воронке» у вебинара: сколько начали, средний процент досмотра, сколько досмотрели.
Без выдуманных данных; без ключей Cloudflare — понятный пустой экран «Вебинары подключаются». Тесты, документация, PR в `main`.
