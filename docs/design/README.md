# Макеты Smartflow (референс для Claude Code)

Это макеты с холста, а не готовый код. Брать из них: цвета, шрифт Golos Text, отступы, радиусы, компоновку и тексты.
Не копировать код как есть: в нём служебная разметка редактора (`<x-dc>`, `support.js`, адреса `/_blob/...`).
Картинки персонажа: m1.png (с планшетом), m2.png (руки в стороны), m3.png (машет).

Палитра: красный #E3121F (срочное, главная кнопка), бирюза #1BC6B4 (хорошие новости, текст на ней #0B2E2A),
чернила #161213, туман #F2F0EF, линии #E6E1DF, второстепенный текст #6A6262, белый #FFFFFF.
Шрифт: Golos Text. Отступы кратно 4: 4/8/12/16/24. Цифры: font-variant-numeric: tabular-nums.

Файлы:
- Palette — палитра и правила
- MK-* — Маркетплейс (каталог, карточка, подключение, состояния, веб, анатомия карточки)
- S-* — маркетолог (карта пути, бриф, конструктор, публикация, доход)
- C-* — клиент эксперта (слои, карта пути, первое касание, урок, оплата, после покупки, не купил)
