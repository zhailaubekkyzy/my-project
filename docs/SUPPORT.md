# Поддержка SmartFlow — руководство для команды

Для кого: человек в команде поддержки (например, студент) и владелица. Программировать не нужно.
Всё делается в самом приложении: **Профиль → «Панель поддержки»** (кнопку видит только команда).

## Как устроено

| Что | Где видно |
|---|---|
| Номер человека `SF-48213` | У каждого внизу Профиля и в чате «Поддержка». По нему человек находится однозначно. |
| Код ошибки `K7P2` | Человек видит его в сообщении об ошибке («… (код K7P2)») или на экране «Этот экран не открылся». Тот же код — в панели (раздел «Ошибки») и в логах Railway вместе с номером человека. |
| Жалоба | Чаты → «Поддержка SmartFlow». К жалобе сами прикладываются: телефон и система, версия Telegram, экран, тема, есть ли интернет, может ли бот писать, последние коды ошибок. Переписки не прикладываются. |
| Уведомление | Бот пишет всей команде о каждой новой жалобе, кнопка «Открыть» ведёт прямо в жалобу. |
| Ответ человеку | В жалобе → «Ответить» или «Ответить и закрыть». Ответ появляется у человека в чате «Поддержка», бот присылает его в Telegram. |
| Журнал команды | Каждое исправление, ответ и просмотр переписки записывается: кто, кому, что было → что стало. |

## Порядок работы с жалобой

1. **Найти человека.** Кнопка «Открыть карточку человека» в жалобе, или поиск на главной панели:
   номер `SF-48213`, `@ник`, имя. Назвали код ошибки — впишите его туда же (4 знака, например `K7P2`).
2. **Понять, где проблема.**
   - **Телефон** — у других всё работает, у него «зависло», старые данные, пустой экран.
   - **Его данные** — не так только в его консультанте, чате, фото, материалах.
   - **Код** — одна и та же ошибка у многих людей.
3. **Починить.**
   - Телефон → «Очистить данные на телефоне». Данные на сервере не трогаются; приложение само очистит кэш при следующем открытии.
   - Данные → кнопка в карточке человека. Сначала показывается «было → станет» и сколько записей изменится. Подтверждаете — меняется только у этого человека.
   - Код → ничего не меняйте. Передайте владелице/разработчику: код ошибки, номер человека, что он делал.
4. **Ответить и закрыть** жалобу.

## Кнопки в карточке человека

| Кнопка | Когда | Что меняет |
|---|---|---|
| Очистить данные на телефоне | Зависло, старое, пустой экран | Только кэш на его телефоне |
| Написать в Telegram | Нужно что-то спросить | Ничего, бот отправляет сообщение |
| Вернуть имя из Telegram | Сломалось имя | Своё имя в приложении |
| Удалить фото | Фото сломано/неприемлемо | Его загруженное фото |
| Включить SI | «SI не отвечает», в чате «SI молчит» | Один чат |
| Скрыть / показать в Маркетплейсе | Жалоба на карточку / просьба вернуть | Один консультант |
| Выключить / включить консультанта | Серьёзная жалоба / ошибочно выключен | Один консультант (переписки сохраняются) |
| Удалить фото консультанта | Фото сломано/неприемлемо | Один консультант |
| Досчитать SI-мозг | «SI не знает мои материалы», есть «не обработано» | Части материалов этого эксперта |
| Заблокировать / разблокировать | Спам, злоупотребления. **Только владелица** | Доступ человека к приложению |

## Частые случаи

- **«Приложение зависло / показывает старое»** → «Очистить данные на телефоне», попросить закрыть и открыть приложение.
- **«SI не отвечает»** → в карточке, в чатах: «SI молчит» → «Включить SI». Если на главной панели «нет ключа OpenAI» — это у всех, сообщить владелице.
- **«Не приходят уведомления»** → в карточке «Бот может писать: нет» → попросить: Профиль → «Уведомления в Telegram → Включить».
- **«SI не знает мои материалы»** → SI-мозг: «не обработано» → «Досчитать SI-мозг». Проверить, что материал открыт нужному SI.
- **«Моего консультанта нет в Маркетплейсе»** → «нет оффера» — эксперт заполняет карточку в Офисе; скрыт командой — «Показать в Маркетплейсе».
- **«Ошибка, код …»** → «Ошибки» → вписать код → видно, кто, где и что. Повторяется у многих — разработчику.

## Правила безопасности

- Меняем только данные человека из жалобы. Кнопки в карточке не трогают других людей.
- Перед подтверждением читаем «было → станет». Ожидали 1 запись, а показывает больше — **не подтверждаем**, пишем владелице. Сервер сам остановит, если число записей изменилось.
- В Supabase руками ничего не правим.
- Переписки открываем только по жалобе. Каждый просмотр записывается в журнал.
- Не просим у людей пароли, коды из SMS, ключи и токены.

## Для владелицы: как включить панель

1. После вливания откройте SmartFlow → Профиль. Внизу — ваш номер, например `SF-48213`.
2. Railway → проект → сервис → **Variables** → **New Variable**:
   имя `ADMIN_USERS`, значение — ваш номер (`SF-48213`). Несколько владельцев — через запятую.
3. Railway сам перезапустит сервер (1–2 минуты). Закройте и откройте приложение → в Профиле появится «Панель поддержки».
4. Чтобы бот писал вам о жалобах, разрешите ему сообщения: Профиль → «Уведомления в Telegram → Включить».

**Добавить студента:** он открывает SmartFlow, диктует номер из Профиля → Панель поддержки → «Команда» → вписать номер → «Добавить».
Убрать — там же, «Убрать». Студент не может блокировать людей и менять команду.

## Для разработчика

- Сервер: `server/routes/admin.js` (панель), `server/services/support-service.js` (номера, коды ошибок, команда, журнал),
  `server/services/support-fixes.js` (кнопки-исправления), `server/routes/support.js` (ошибки с телефона),
  `server/middleware/error-handler.js` (код ошибки в ответе и логе), миграция `006_support.sql`.
- Фронтенд: `js/screens/admin.js` (экраны панели, данные других людей только в памяти, не в localStorage),
  коды ошибок — `js/api-client.js`, сведения к жалобе и защита от сломанного экрана — `js/app.js`.
- Новое исправление: запись в `FIXES` (`plan()` — что изменится и сколько записей, `apply()` — само изменение) и кнопка в `js/screens/admin.js`. Тест — в `test/stage1.test.js`.
- Ошибки хранятся 60 дней (`error_log`).
